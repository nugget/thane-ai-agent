## Session Archive & Rich Metadata

Thane now remembers everything. Complete immutable transcript archive with full-text search, gap-aware context expansion, and LLM-generated session metadata.

### Session Archive (PR #78)
- **Immutable transcript storage** — every message and tool call preserved in `archive.db`
- **FTS5 full-text search** with graceful LIKE fallback when FTS5 unavailable
- **Gap-aware context expansion** — uses silence detection (default 10min) to find conversation boundaries, not rigid ±N message counts
- **Archive tools** for the agent: `archive_search`, `archive_sessions`, `archive_session_transcript` (supports short ID prefixes)
- **6 REST API endpoints** for archive access
- **OpenClaw import tool** (`openclaw-import`) — migrate existing OpenClaw sessions into Thane archive
- 38 tests in memory package

### Rich Session Metadata (PR #80, #82)
- **Structured metadata** generated by LLM on session close: title, tags, multi-length summaries (one-liner, paragraph, detailed), key decisions, participants, session type, tools used
- **Configurable metadata model** (`archive.metadata_model`) — use cheap local models for async summarization
- **Schema auto-migration** — safely adds columns to existing databases
- **Graceful JSON fallback** — if LLM returns unparseable JSON, raw text becomes the summary

### Log Sanitization (PR #84)
- **Fixed:** Ollama chat handler was logging full conversation content (raw_body) at INFO level
- INFO log now shows: remote_addr, remote_ip (via X-Real-IP/X-Forwarded-For), user_agent, model, message count, stream flag
- Full headers and body length available at DEBUG level only

### Documentation (PR #77)
- Added `AGENTS.md` for AI coding agents
- Comprehensive docs housekeeping
- Quickstart improvements
