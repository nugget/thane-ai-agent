## Highlights

### Content-Addressed Attachment Store (#560, #561, #562)
Full attachment pipeline: content-addressed storage with SHA-256 dedup, SQLite metadata index, vision analysis with 3-tier caching, and agent tools for search/list/analyze. Signal bridge integrated; all channels share dedup and metadata.

### Git-Backed Provenance Store (#556)
Signed, auditable file store for ego.md and metacognitive.md. Every write is a git commit with SSH signature enforcement, providing a tamper-evident history of agent identity and state evolution.

### MQTT Telemetry Publishing (#563, #564)
25 operational sensors published to Home Assistant via MQTT Discovery: DB sizes, token usage (24h rolling with per-model breakdown), active sessions, request latency percentiles, loop states, and attachment metrics. Configurable interval, handler-only loop.

### Force-Directed Dashboard Canvas (#546)
Physics simulation replaces circular layout: center gravity, spring forces, pairwise repulsion, parent-child clustering. Delegate tool calls render as ephemeral child nodes. Trust zone underglow halos, category icons, sleep ring progress indicators.

### Loop Infrastructure Migrations (#549)
HA state watcher and MQTT publisher migrated from ad-hoc goroutines to loop infrastructure. Event batching reduces iteration spam from rapid HA state changes.
