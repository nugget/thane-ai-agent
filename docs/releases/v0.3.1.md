# v0.3.1: Context Injection

## Features
- **Static context injection** (#87, #88) — New `context.inject_files` config reads files at startup and injects into system prompt. Agent no longer wastes iterations reading key files like `~/.agents.md` or `MEMORY.md`.

## Fixes
- **Tilde expansion** (#85) — `file_read`/`file_write` now expand `~` to home directory
- **Iteration limit** (#86) — Agent loop limit increased from 10 to 50
- Copilot review fixes: comment ordering, error specificity, tilde edge cases
- Sanitized personal paths from example config

## Deployment Notes
- New macOS binaries need `codesign -s -` after build (ad-hoc signing)
- Add `context.inject_files` to your config.yaml to use the new feature
