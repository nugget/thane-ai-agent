# v0.4.0: Cost-aware Model Routing with Conversation Isolation

## Highlights

Cost-aware model routing, per-chat conversation isolation for Open WebUI, and extensive hardening against tool call hallucinations. Reduced per-interaction Opus cost from ~$2-5 to ~$0.20 through conversation isolation and cost-penalized routing.

## Router

- **Cost-aware scoring** — expensive models penalized by tier × complexity (simple=-45, moderate=-24, complex=-9 for tier 3); free model bonus +15
- **Hint system** — callers supply `channel`, `mission`, `quality_floor`, `model_preference`, `local_only` to influence routing
- **Routing profiles as Ollama model names** — `thane:latest`, `thane:thinking` (quality≥9), `thane:fast` (speed/cost), `thane:homeassistant` (HA device control), `thane:local` (free models only)
- **Improved tiebreaker** — equal score + equal cost prefers higher quality model

## Conversation Isolation (#95)

- Each Open WebUI chat gets its own `owu-<hash>` conversation ID derived from the first user message
- Thane's memory is the sole source of truth — only the new user message is extracted from OWU requests
- Eliminates cross-chat context pollution and history duplication that was doubling input tokens

## Tool Call Hardening

- **Concatenated JSON parsing** — handles qwen-style `{...}{...}` tool call format
- **Stream buffering** — holds back tokens starting with `{` when tools are available to prevent raw JSON leaking to clients
- **Hallucinated tool call suppression** — JSON with invalid tool names suppressed at WARN level
- **Trailing JSON stripping** — removes tool call objects appended to end of prose responses
- **Loop detection** — breaks after 3 identical tool+args repeats with error nudge to model

## Tools

- `conversation_reset` — agent can archive and clear conversation on explicit user request; uses context-propagated conversation ID

## Search & Archive

- **FTS5 query sanitization** — wraps terms in double quotes to prevent syntax errors
- **Result size caps** — search 16KB, transcript 32KB with UTF-8 safe truncation

## Observability

- `tok_per_sec` in response logs (output_tokens / elapsed)
- `resp_model` alongside requested model (catches provider misrouting)
- Forensic debug logging for model selection paths and compaction decisions
