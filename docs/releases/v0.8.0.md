Phase 4: Presence. Thane now pushes actionable notifications with human-in-the-loop callbacks, syncs contacts natively via CardDAV, monitors media feeds, and exposes a full web dashboard for operational visibility.

**293 files changed, 32,671 insertions, 4,527 deletions across 136 commits.**

## Highlights

### Actionable Notifications & HITL
- Provider-agnostic notification routing with pluggable delivery channels
- `send_notification` for fire-and-forget push via HA companion app
- `request_human_decision` for actionable notifications with callback tracking
- MQTT callback listener for human-in-the-loop decision responses
- Timeout escalation — unanswered decisions auto-escalate after configurable deadline
- Callback prefix and MQTT topic derived from device name for multi-instance support

### CardDAV Server
- Native contact sync with macOS Contacts.app, iOS, and Thunderbird via RFC 6352
- Backed by the same contact store the agent uses — edits sync both ways
- Basic Auth, configurable bind addresses, dynamic interface rebind for Tailscale/VPN
- Trust zone-aware vCard export — sensitive fields stripped for lower zones

### Contact Directory Overhaul
- Schema v2: vCard-aligned structured identifiers replacing ad-hoc contact_facts
- Formalized trust zone policy matrix (owner/admin/household/trusted/known/unknown)
- VCF import/export tools with trust-zone filtering and QR code generation
- Cascading contact resolution with preferred_name and fuzzy search
- Rich context injection for channel conversations — the agent knows who it's talking to
- Apple X-ABLABEL and PRODID filtering for clean vCard imports

### Media Analysis Vault
- RSS/Atom feed monitoring with periodic polling and new-entry detection
- YouTube channel and playlist subscriptions (`@handle`, `/channel/`, `/playlist?list=`)
- Feed auto-discovery from blog/podcast page URLs
- `media_save_analysis` outputs structured analysis to Obsidian-compatible markdown
- Engagement tracking for dedup and follow-up
- Trust zone parameter for one-off transcript analysis

### Web Dashboard
- Operational visibility with data browsers for contacts, facts, sessions, tasks, and anticipations
- Session inspector with NLE-style timeline visualization
- Live transcript streaming for active sessions
- Iteration-level execution tracing — see every tool call, every decision
- HTMX + Go templates, sanitized markdown rendering

### GitHub/Forgejo Integration
- 18 native forge tools: issues, PRs, code review, diffs, CI checks, merge, search
- Dynamic forge context injection for delegates and sessions
- Multi-account support with provider routing

## Agent Loop & Capabilities

- **Capability tag refresh** — `request_capability` activations take effect immediately instead of being stale until next session (#507)
- **Tag index propagation** — `FilteredCopy`/`FilteredCopyExcluding` preserve tag awareness for chained filtering
- **Illegal strike counter** — only resets on non-meta tool success, preventing infinite loops with capability management tools
- **Channel-pinned tags** — conversation source auto-activates relevant capability tags; `drop_capability` can't shed them
- **Delegate tag scoping** — delegates inherit capability tags from the orchestrator session
- **Capability context loading** — tags load associated knowledge base documents alongside tools
- **Recovery iteration** — agent gets one more chance after illegal tool calls before breaking

## Delegation & Reliability

- **Non-cooperative tool timeout** — delegates enforce deadlines even when tool handlers ignore context cancellation (#508)
- **Deadline vs cancellation distinction** — error messages differentiate `DeadlineExceeded` from `Canceled`
- **Leaked goroutine logging** — `slog.Warn` when context fires before handler returns
- **Delegate sessions** — delegate executions are first-class archive sessions with full transcripts
- **Execution summaries** — delegates return structured iteration/duration/tool-call summaries to orchestrator

## Database & Storage

- **Unified database** — all tables consolidated into single `thane.db` (#434)
- **Unified message storage** — lifecycle status column replaces compaction booleans
- **Unified tool call storage** — lifecycle tracking for tool executions
- **Opstate TTL** — operational state store supports time-to-live for poller cursors and feature flags
- **Resilient timestamp parsing** — handles SQLite TEXT column edge cases without silent data loss

## Media & Feeds

- **Playlist subscriptions** — `/playlist?list=` URLs rewrite to Atom feed URLs (#518)
- **Feed discovery** — HTML page auto-discovery for blog/podcast URLs
