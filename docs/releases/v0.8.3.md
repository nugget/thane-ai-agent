# v0.8.3 — Loop Infrastructure & Cognition Engine

Loop infrastructure becomes the runtime backbone of Thane in this release. The core process registry and new `WaitFunc`/`Handler` primitives land, the metacognitive loop becomes the first real consumer of that model, and the first Cognition Engine dashboard arrives to show the system's live runtime, loops, and iteration activity in one place. This release also adds `logs_query` for SQLite log self-diagnostics and retires the old web dashboard package in favor of the new runtime UI foundation.

**81 files changed, 12,288 insertions, 7,734 deletions.**

## Highlights

### Loop Infrastructure & Process Registry (#509, #542)
- New loop process registry for long-lived autonomous runtime work
- New `WaitFunc` and `Handler` primitives for event-driven and handler-style loops
- Metacognition reimplemented as the first real loop consumer
- Clearer path for migrating background services off ad hoc goroutines and into one shared lifecycle model

### First Cognition Engine Dashboard (#534)
- New live dashboard for the runtime and active loops
- Iteration timelines with model, token, and context details
- Runtime/system node, parent-child linking lines, service health badges, and live activity indicators
- Popup inspector, log drill-down, and SSE-driven updates for watching loop state in real time

### Runtime Migrations onto Loop Infrastructure (#544)
- Email poller migrated to the loop runtime
- Media feed poller migrated to the loop runtime
- Signal bridge registered with loop infrastructure
- Open WebUI conversation tracker registered with loop infrastructure
- UniFi poller migrated to the loop runtime
- Demo loops added to exercise and refine the dashboard experience

### Operational Diagnostics
- New `logs_query` tool for querying the SQLite log index directly (#533)
- `session_id` and `request_id` now propagate to post-run log lines, improving indexed self-diagnostics

### Cleanup
- Removed the old web dashboard package as a clean slate for the new runtime dashboard work (#536)
