# v0.10.0 — The Loop Corpus Release

v0.10.0 is the release where Thane's loops stop being hand-coded service
routines and become a managed corpus. v0.9.x made the context the model sees
trustworthy; v0.10.0 asks the next question: can the loops themselves — the
ego, the metacognition, the archivist, every container and child — be
declarative data that an operator can inspect, reparent, and reason about the
way they already reason about documents?

The answer is now mostly yes. Loop trees gain a real structural root, parent and
child containers with cascading tags and runtime settings, and a single
canonical row — the LoopView, our "ps auxwwww" for cognition — shared across
every tool and surface. The web console was rebuilt from the ground up on the
native /v1 API, with a Gource-style force-directed graph and a
progressive-disclosure inspector reading that same canonical view. The HTTP
surface itself became a self-documenting product, with OpenAPI specs, an
embedded Scalar explorer, and CI guardrails that keep the docs honest. And the
data substrate underneath swapped its SQLite driver to pure Go, fixing the FTS5
bugs that had silently disabled full-text search in production.

This was also a cycle defined by production incidents — a curator wake-storm
that DoS'd interactive turns, a host-OOM restart loop, frontmatter escaping that
ballooned a managed doc to 32MB, and a "narrate-then-stop" stall where the
engine was erasing the model's own reasoning. Each got a root-cause fix, and the
breaking surface reflects a sustained vocabulary consolidation pass that
replaced ad-hoc terms with canonical ones across tools, schemas, and prompts.

**625 files changed, 75,407 insertions, 15,979 deletions.**

## The loop corpus

The marquee work this cycle reshaped the loop graph into a managed corpus
mirroring the document corpus. The "#889" container line introduced parent/child
loops with tag inheritance (#888), subscriptions modeled as a loop attribute
(#890), effective-vs-declared surfaces (#891), and runtime settings and
conditions cascading through ancestors (#892, #893). That tree was then given a
real spine: `operation: core` became the structural root, with `core`
canonicalized so every loop hangs off one place (#894), followed by a series of
cascade-correctness and hydration hardening passes (#895, #896, #897).

On top of that foundation sits the canonical LoopView — one rich row, shared
across every loop tool, that reads like `ps auxwwww` for cognition (#1104). It
is now exposed on the /v1/loops payload (#1120) and backs the new console
inspector. Operators and agents can move a loop between containers and relaunch
it with `loop_reparent` (#1105), wake a live loop with a directed message via
the restored `loop_wake` (#1107), and make field-scoped partial edits with
`loop_definition_update` (#1111) instead of full-replace. `loop_status` grew a
`next_wake_delta`, `current_sleep_duration`, and a health rollup (#1108), and the
loop-definition spec schema is now enumerated so agents can read its shape,
including the structural `parent_name` field with a warning when metadata shadows
it (#1088, #1103).

The #1086 line made the service loops themselves declarative: ego,
metacognition, and archivist prompts are now data, not hand-coded routines
(#1089, #1092), and `thane_curate` exposes `quality_floor`, `exclude_tools`, and
`metadata` directly (#1091). Early in the cycle every wake path — MQTT, Signal,
OWU, API chat — was routed through one common turn builder (#847–#851), and
prompt assembly was rebuilt as an inverted pyramid with a first-class mission
section (#876, #877). The marquee correctness fix landed late: the turn engine
was erasing the model's pre-tool-call reasoning, which was the root of the
production narrate-then-stop stall where the model would promise a tool call,
narrate it, and end the turn without ever emitting it (#1112).

## Web console & graph

The operator-facing web console was rebuilt from the ground up on the native /v1
API. The release first consolidated the separate web and API surfaces into a
single loops-first HTTP handler (#1048), then shipped the new console UI on top
of it and retired the old dashboard (#1049). From there the graph evolved
quickly: a container-aware node graph with a CSS attribute-projection seam for
theming (#1062), built-in grouping containers for cognition, home-assistant, and
channels (#1118), and then a wholesale physics rewrite into a Gource-style
overdamped force model with rim-spring child-edge layout and a real node visual
language — size encodes capacity, a fill-ring shows context usage, glyphs and
opaque occlusion carry the rest (#1119).

The capstone is a progressive-disclosure loop inspector — glance, live feed,
spec — backed by the canonical LoopView (#1120), alongside a hardening pass for
bug fixes, accessibility, and static-asset caching (#1117). Two earlier
graph-correctness fixes cleaned up the pre-rebuild dashboard: a duplicate "core"
node collapsed into one (#974), and its orphaned children re-rooted so they no
longer floated free in the orbit layout (#996).

## API, OpenAPI & docs

v0.10.0 turned Thane's HTTP surface into a self-documenting product. The
loops-first /v1 rebuild shipped OpenAPI specs and an embedded Scalar /docs
explorer (#1047), the handler migration consolidated the old web and API
surfaces onto one native code path (#1048), and /v1/conversations became
queryable and paginated, killing the N+1 full-dump (#1061).

The #1060 documentation campaign ran end to end: CI drift guardrails with
vacuum-lint and route-coverage (#1063), the info block, tag groups, and Scalar
config (#1064), then schema, operation, and parameter description coverage phase
by phase (#1065, #1066, #1067, #1070), capped by response examples with the lint
gate flipped to error severity (#1069). #1080 then added a relative "Try-it"
server for the native docs, reworked the docs taxonomy, and renamed insights to
telemetry. Net effect: the API is queryable instead of dump-only, the docs are
enforced-complete with live examples, and both operators and agent loops read
from accurate, schema-backed surfaces.

## Data, storage & integrations

The headline storage move was migrating the SQLite driver from CGO-based
mattn/go-sqlite3 to pure-Go modernc.org/sqlite (#1077), which along the way
fixed the FTS5 production bugs that had silently disabled full-text search.
Memory and archive matured from a fragmented set into a unified, FTS5-backed
search surface spanning raw logs, sessions, and working memory (#982, #983,
#1020), and the event-woken curator that had caused a production wake-storm was
replaced by a self-paced archivist queue consumer (#1025, #1031).

Home Assistant grew from thin context into a first-class integration with roughly
a dozen new tools — predicate search across live state (#1009), glob matching and
live-glob subscriptions (#1012, #1014), `ha_device`, `ha_history`, and
`ha_home_snapshot` (#1016, #1018, #1019), did-you-mean suggestions on a missing
entity_id (#1022) — plus a self-healing WebSocket connection (#1027). Two
production data-integrity incidents drove defensive fixes: frontmatter escaping
amplification that doubled backslashes each curate cycle and eventually wedged a
managed doc (#1101), and unbounded document reads causing OOM, now size-capped
(#1052). Resilience work also covered orphaned MQTT wake subscriptions (#1057)
and transient UniFi gateway flapping (#1122), and the code adopted the Claude
Opus 4.8 / Sonnet 4.6 / Haiku 4.5 model IDs (#1026).

## Reliability & infrastructure

Each defining incident of the cycle got a root-cause fix. The curator wake-storm
that saturated the model backend and DoS'd interactive turns gave way to the
self-paced archivist queue (#1025). The runaway memory growth behind the host-OOM
restart loop is now caught by an in-process memory guard that writes a heap dump
at the soft limit and exits non-zero at the hard limit so the supervisor actually
relaunches (#1051, #1053). Content-resolution that was corrupting loop output
refs and killing maintained-doc loops at wake was fixed (#1074), and a live
egress hole closed when `thane_curate` loops moved to default-deny on
human-egress tools (#1087, closing #696).

Underneath, the `just ci` gate was reworked to be hermetic and parallel with
caching (#1097), the justfile tidied and the dead loops-ng harness removed
(#1099), release-artifact integrity hardened against the macOS auto-updater
contract (#1100), the vacuum lint de-flaked (#1083), and a steady stream of
dependency bumps kept current. A final pre-release audit swept docs, code
hygiene, and model-facing contradictions before the tag (#1093, #1094, #1095).

## Breaking changes & upgrade notes

This is a vocabulary-and-contract consolidation release, so plan for the
following before upgrading.

**Removed tools.** Drop any references to `thane_wake` and `notify_loop` (#865),
`list_loaded_capabilities` (#920), and the tag-alias system (#957). Directed loop
wake is now `loop_wake` (#1107), and loop-definition edits should prefer the new
field-scoped `loop_definition_update` over the old full-replace patch (#1111).

**Rename sweep.** Update configs, metadata, and prompts: Hints → RoutingFactors
with a new `delegation_gating` field (#885), `focus_tag` → `scope_tag` (#884),
`entry_point` → `trailhead` (#909), always-available/always-active → core (#921),
delegate `Profile` → `RunPolicy` (#959), curator → archivist (#1025), and
insights → telemetry (#1080).

**Loop authoring.** `thane_curate` no longer accepts an implicit cadence — loops
must declare an explicit sleep envelope (#882); `QualityFloor` changed from string
to int (#900); guidance and instructions unified onto `Profile.Instructions`
(#883); and human-egress tools now default-deny on curate loops (#1087). Loop
trees are now rooted at the structural `operation: core` root, so any graph or
definition assuming the old rooting must be reviewed (#894), and `parent_name`
placed in opaque `spec.metadata` instead of the real field now warns and lands
the loop under core (#1103).

**Database.** The SQLite driver swapped from CGO mattn to pure-Go modernc (#1077).
Never call `sql.Open("sqlite", …)` directly — go through `database.Open` /
`DriverName` so the `sqlite-thane` wrapper forces `_time_format=sqlite` for
timestamp byte-stability against old rows. Audit prod `thane.db` default-shape
rows before cutover. The migration also turns FTS5 on by default, which was
previously off in tagless CI builds.

**Model IDs.** Update model config to Claude Opus 4.8 / Sonnet 4.6 / Haiku 4.5
(#1026); operators on pinned older IDs should confirm references point at the new
ones.

**Process supervision.** memguard now exits non-zero on a hard-limit restart so
the macOS supervisor relaunches the process (#1053) — expect and watch for these
automatic restarts, and collect the heap dumps.

**API consumers.** /v1/conversations is now paginated and queryable with a changed
response shape (#1061); integrations relying on the unbounded full dump must adopt
the pagination/query parameters. The web and API surfaces are consolidated onto
the native /v1 loops-first handler (#1048), so any client pinned to the legacy
split endpoints must move. The OpenAPI examples lint now fails the build at error
severity, so contributor spec changes lacking required response examples will
break CI (#1069).

**Documents.** Managed-doc frontmatter now round-trips via `strconv.Unquote` to
stop escaping amplification; docs corrupted by the prior asymmetry must be
repaired (#1101). Document reads are now size-capped to prevent OOM, so oversized
files are truncated or refused rather than loaded whole (#1052).

**Operator tooling.** The `deploy-macos` just recipe was renamed and the dead
loops-ng harness removed (#1099); rebuild and re-publish releases through the
standard releng path rather than reusing pre-#1100 artifacts (#1100).
