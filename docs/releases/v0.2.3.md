## What's New

### httpkit: Centralized HTTP Client (#71)
- New `internal/httpkit` package — single source of truth for all outbound HTTP
- Shared transport with explicit dial (10s), TLS handshake (10s), response header (15s) timeouts
- Connection pooling: 20 max idle, 5 per host, 90s TTL, HTTP/2
- Auto User-Agent injection (`Thane/<version>`)
- `ReadErrorBody()` and `DrainAndClose()` utilities for bounded reads and pool hygiene
- Migrated all 7 HTTP client packages
- 100% test coverage on httpkit core

### Retry Transport for Transient Errors (#75, closes #53)
- New `retryTransport` detects transient dial failures (EHOSTUNREACH, ENETUNREACH, ECONNREFUSED)
- Configurable retry count and delay via `WithRetry(count, delay)`
- Respects context cancellation during retry delay
- Safe body rewinding for POST requests
- Enabled on HA client: 2 retries, 500ms delay
- Root cause: macOS ARP table race condition on LAN hosts

### Agent Loop Fix (#74, closes #72)
- Agent no longer drops responses when tool calls exhaust maxIterations
- Recovery path: makes one final LLM call with tools disabled to compose answer
- Bumped maxIterations from 5 to 10

### LLM Timeout Tuning (#75)
- Anthropic: ResponseHeaderTimeout increased to 120s (fixes compaction timeouts)
- Ollama: ResponseHeaderTimeout increased to 5m (accommodates model loading)

### Other
- Removed curl subprocess workaround from Home Assistant client — native Go HTTP
- golangci-lint v2 migration (#70) with 5 staticcheck fixes
- Copilot review feedback incorporated across PRs
