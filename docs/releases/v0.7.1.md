# Thane v0.7.1

**39 commits, 71 files changed, +13,656 / -224 lines**

A major feature release building on v0.7.0's foundation: native media integration, metacognitive self-monitoring, Signal UX improvements, and infrastructure hardening across the board.

## 🎬 Native Media Integration

**`media_transcript` tool** — fetch transcripts from YouTube, Vimeo, podcasts, or any of yt-dlp's 1000+ supported sites. (#354, #360, PR #355)

- VTT cleaning pipeline: deduplicates rolling captions, strips timing/HTML, creates paragraph breaks at natural pauses. Output is ~25-30% the size of raw VTT.
- **Map-reduce summarization**: transcripts are chunked at paragraph boundaries (~5K per chunk), summarized in parallel by a local model, then assembled into a unified summary. Three detail levels: `full`, `summary` (~2-3K chars), `brief` (~500 chars).
- **Focus-guided extraction**: pass a `focus` parameter to emphasize specific topics across both map and reduce phases. Same video, different summaries depending on the question.
- Durable transcript storage with YAML frontmatter in a configurable `transcript_dir`.
- Cookie support for authenticated content.

## 🧠 Metacognitive Self-Monitoring Loop

A perpetual background loop that observes the environment and self-determines its attention cycle. (#319, #327, #334)

- Adaptive sleep: 2m–30m based on activity level, with jitter to prevent synchronization.
- Normal iterations look outward (environment scanning); supervisor iterations (~10%) look inward (self-assessment).
- Router quality floors: routine iterations use local models, supervisor iterations reach frontier.
- `update_metacognitive_state` tool for structured state management.
- **Real-world win**: detected a dead Z-Wave node (garage entry lock) and proactively notified the owner.

## 💬 Signal Bridge Improvements

- **Typing indicator refresh** — continuous "breathing" indicator during long processing. Re-sends every 10s to keep Signal's ~15s timeout indicator alive. (#357)
- **Reaction handling** — incoming emoji reactions wake the agent with contextual hints (emoji, target message, sender). Removals are logged but don't wake. (#358)
- **Attachment receiving** — images, documents, voice notes received and copied to workspace with metadata descriptions. Path traversal protection, size limits, filename collision handling. (#359)
- **Session rotation farewell** — when an idle session rotates, Thane generates a personality-matched farewell message and carry-forward summary via LLM, sends the farewell to the channel, and injects carry-forward into the next session. Previously, idle rotation silently dropped all context. (#363)

## 🔧 Native Forge Integration

Replaced the MCP GitHub server with a native Go implementation. 18 tools behind a `ForgeProvider` interface designed for multi-provider support (GitHub, Gitea, future forges). (#321, PR #339)

- Read-only tools (`forge_issue_get`, `forge_pr_get`) always available; 16 write tools gated behind the `forge` capability tag.
- Full PR review workflow: diff, files, commits, reviews, inline comments, CI checks, merge.
- Eliminates the MCP server process and its startup/communication overhead.

## 🔍 Search & Recall Fixes

- **FTS5 OR semantics** — `archive_search` and `recall_fact` now use OR between search terms instead of implicit AND, dramatically improving recall for multi-word queries. (#356, PR #361)
- **Column ambiguity fix** — `recall_fact` FTS5 JOIN no longer fails with "ambiguous column name: key", eliminating silent fallback to LIKE search.

## 📊 Cost Tracking

SQLite-backed usage recording with config-driven model pricing. `cost_summary` tool provides token and spend visibility per model, per time period. (#320, PR #325)

## 🏗️ Infrastructure

- **Temp file abstraction** — `create_temp_file` + `temp:LABEL` references for orchestrator-delegate data passing. Labels resolve to paths at runtime; automatic lifecycle cleanup. (#322, PR #323)
- **Subject-keyed fact injection** — facts tagged with `subjects` JSON array, `GetBySubjects()` retrieval, `SubjectContextProvider` for pre-warming system prompts with relevant knowledge. (#338, PR #342)
- **Email tool hardening** — type coercion for UIDs (float64/int/string), singular `uid` convenience alongside `uids` arrays, `folder`→`destination` alias in `email_move`. (#365, PR #366)
- **Response text duplication fix** — prevented doubled output when model returns text + tool_call in same iteration. (#347, PR #349)
- **Summarizer empty session fix** — skip sessions with stale message counts. (#341, PR #346)
- **Conversation history as JSON** — structured format in system prompt. (#324, PR #326)

## 📄 Documentation

- **Trust architecture design document** — maps structural enforcement controls (trust zones, tool gating, capability tags, egress gates, router quality floors) and identifies behavioral gaps. Grounded in Anthropic's 16-model research showing 96%→37% compliance rates. (PR #345)

## Config Changes

New configuration sections for this release:

```yaml
media:
  cookies_file: ""                    # optional, for authenticated content
  subtitle_language: "en"
  max_transcript_chars: 50000
  transcript_dir: ""                  # durable storage path
  summarize_model: ""                 # optional routing hint

metacognitive:
  enabled: true
  state_file: "metacognitive.md"
  min_sleep: 2m
  max_sleep: 30m
  default_sleep: 10m
  jitter: 0.2
  supervisor_probability: 0.1

signal:
  attachment_source_dir: ""           # signal-cli attachment storage
  attachment_dir: ""                  # workspace copy destination
  max_attachment_size: 0              # 0 = no limit
```
